# 固件骨架（可稍后烧录，不是已烧录工程）

这份目录提供注释清楚的 `main.c` 与 PlatformIO 工程入口，协议与 `../scripts` 模拟流一致。

**模拟已在盒子上跑通页面与数据流；实机未验证。** 云电脑上没有这块板，未做编译（若本机没有 `arm-none-eabi-gcc` / PlatformIO 工具链）、未烧录、未插串口。

## 板型：已确认与仍未知

- 已确认：主人于 2026-11-11 说明，这是 **正点原子 STM32F407ZGT6 开发板**。
- 仍未知：具体是哪一套件、已接哪些传感器；未见原理图。引脚、晶振、板载 LED 仍按常见 F407ZGT6 开发板习惯做假设，见 `src/main.c` 顶部注释，须对照该套件原理图再核对。
- 实机未烧录，云电脑上没有这块板。

## 协议

见 `include/helix_env_protocol.h`。与 Atlas 模拟 USART 样本相同：一行 key=value，假设 115200 8N1，`\r\n` 结尾。
板端无 RTC 时打印 `TS=UNSYNCED`，由主机补时间。不要改 key 名称。

## 稍后在有板子的电脑上

1. 对照该正点原子套件原理图，确认 USART/I2C 引脚是否与假设一致。
2. 安装 PlatformIO 或 STM32CubeIDE，确认 `board` 标识。
3. 用开发板例程补全 `SystemClock_Config()`（必须与 HSE 匹配）。
4. 接入传感器驱动后，把 `ReadSensors()` 的占位值换成真实读取；读失败时用 `WARN`/`FAULT`，不要编造读数。
5. 用 USB 转串口接 PA9/PA10（或你板子上实际的调试串口），波特率 115200。
6. 电脑端把串口收到的行按同样字段解析，即可接到本目录的接入脚本（目前盒子上用的是文件模拟流，不是 `/dev/tty`）。
