## 阅读建议

1. 先看《规范与时间节点》开头的「查证范围与限制」，再看全校规定和本专业学位标准里与毕业论文直接相关的条款。
2. 信息科学与工程学院本院的开题/中期/答辩具体日程、本院文字复制比数值，本次**公网未能核到**。其他学院的时间表只可作参照，不能当成信息学院的安排。
3. 再读《相近方向文献》。每条都区分了「已读到的」和「不宜外推的」。规模很大或数据并不公开的论文，只借方法结构，不当作单机毕设模板。选题 A 用第 1–4 条即可；选题 B、C 看 E 节追加部分。
4. 最后看《候选方向》。如果只看结论，可先读该文件开头的三句话清单。STM32 完整型号已由主人确认为正点原子 STM32F407ZGT6 开发板；已接传感器与具体套件仍未见清单。
