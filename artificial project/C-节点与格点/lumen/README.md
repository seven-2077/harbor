# 节点与格点 — 方向样品

这是一份**方向样品**，不是已经确定的毕业设计题目，也不代表唯一候选。它沿着「软硬结合的场景传感」做成：本地节点半小时采集，对照公开室外环境小时序列，用来讨论教室、办公或场馆的环境监测方法。不是纯艺术装置，也不是没有硬件故事的纯大屏。

主件是可交互页面，海报是同一主题的静态展板。作者向：Seven（何谭昕）。设计署名：Lumen。与选题 A（`../`，时刻的坡度）同属一套部门作品的兄弟样本，字体复用 A 已落地的 IBM Plex / Newsreader / Noto Serif SC，氛围改为室内仪器 / 节点装置。数据以 Atlas 提供的模拟流与公开小样本为准。

本目录是选题 C 的单独成品。请不要改动 `../` 根目录里 A 的现有文件。

## 如何打开

单机即可，不依赖网络 CDN。脚本与数据在本目录；主体字体在上一级 `../fonts/`，本目录只补了一份 C 页面多出来的汉字子集 `fonts/NotoSerifSC-c.woff2`，没有复制 A 的字体文件。

**推荐：直接用浏览器打开主件**

- 双击 `index.html`，或用浏览器打开该文件（`file://` 即可）。
- 海报原件是 `poster.html`；交付用的锁字静态图是 `poster.png`（以及 `poster.pdf`）。

**可选：本地静态服务**（不是必须）

在本目录执行：

```bash
python3 -m http.server 8767
```

然后访问 `http://127.0.0.1:8767/index.html`。若从更上一级的 `lumen/` 打开，相对字体路径同样有效。

交互：在三条室内时序上拖曳（或按左右方向键）读取某一瞬间。右侧给出重叠整点对照、稳态与设计口径、片内温度，以及未标定的气体示意指数。底部 7 天室外温度与 PM2.5 只作上下文，竖标是唯一对照整点 12:00。室内没有一周采样。

## 用了哪份数据（来自 Atlas）

未另爬全量，未改数值。细节见 `data/SOURCE.md`。原文拷贝在 `data/raw/`。

1. **室内节点流（模拟，非实机）**  
   `stm32_sim_stream_2026-08-03T12_30min.csv` 与同名 `.jsonl`。  
   文件头第一行即为「模拟，非实机」。窗口：2026-08-03 12:00:00–12:30:00（Asia/Shanghai），间隔 10 秒，181 个周期，7 个通道。  
   **云电脑没有实物板，未烧录、未实采。** 全部数值为发明的演示值。该流仅松散参考了同日 12:00 室外温湿度气压的量级，室内均值与整点之差是样品构造，不是实测房间效应。

2. **室外气象与空气质量（公开模式格点）**  
   `openmeteo_lanzhou_weather_2026-08-03_to_2026-08-09.csv`  
   `openmeteo_lanzhou_air_quality_2026-08-03_to_2026-08-09.csv`  
   请求点约 36.06°N, 103.83°E，时区 Asia/Shanghai，2026-08-03 至 08-09，各 168 条小时记录。接口将气象与空气质量吸附到不同格点。  
   **这是兰州市区参考点的模式格点产品，不是兰大校园测站，也不是实测坐标。**  
   **许可证**：数据为 CC BY 4.0。须署名，写明 **Weather data by Open-Meteo.com**。空气质量还须归属 **Copernicus Atmosphere Monitoring Service（CAMS）**。CSV 未写模式名称或网格间距，不能断定具体模式或公里网格。出处：https://open-meteo.com/

对照只能落在重叠的那一小时：2026-08-03 12:00 整点。室外是整点小时值，页面不对室外做 10 秒插值。

获取记录日期：2026-11-11（Asia/Shanghai）。口径以 Atlas `选题BC-方法与数据说明.md`、`samples/样本说明.md` 为准；Helix `sensing/` 只作字段与注意事项的格式参考，本页不复刻其看板皮肤。

## 哪些是算出来的，哪些是设计解读

**由样本算出（事实；数值本身仍来自模拟流或公开格点）**

- 室内各通道的均值、极差、标准差、首末五分钟均值，以及 181 个采样点的时序。
- 与 2026-08-03 12:00 室外整点值的并排数字（温度 25.8 °C、相对湿度 49%、气压 852.4 hPa；PM2.5 3.4 μg/m³ 等）。
- 室外一周温度范围 14.3–33.2 °C，PM2.5 范围 1.0–24.7 μg/m³。
- 设计口径下的落入计数：温度 20–26 °C 为 0 / 181（全部略高于上沿，最低 26.18 °C）；相对湿度 40–60% 为 181 / 181；照度 ≥ 300 lx 为 61 / 181。计数是按该口径套到本条模拟流上得出的，口径本身不是标准。

**推断或设计解读（已在画面标明）**

- 主人已确认板型为 **正点原子 STM32F407ZGT6 开发板**（2026-11-11）。具体是哪一套件、已接哪些传感器仍未见清单；固件与页面数据均为模拟，未实机烧录。
- 传感器品类、总线与引脚（BME280 / BH1750 / MQ135 及 I2C1、ADC1）均为推断，不是已核实的物料表。
- MQ135 的气体指数由原始 ADC 按发明系数换算，不是标定 ppm，不得与 CAMS 的 μg/m³ 做数值等同比较。
- 片内温度 MCU_TS 更适于相对变化，**不能当作室内气温**。本列仍是模拟值。
- 舒适带 20–26 °C、40–60%、阅读照度 300 lx 是设计口径，不是国家标准，也不是本样品的实测结论。
- 不把格点写成校园站，不断定模式名称或网格间距。
- 中文标题「节点与格点」是样品名称，不是已定的毕业设计题目。

## 目录

- `index.html` — 可交互主成品（双击可打开）
- `poster.html` — 海报排版原件
- `poster.png` / `poster.pdf` — 锁字静态海报
- `data/` — 小样本原文、SOURCE.md、衍生 `specimen.js`
- `fonts/` — 仅 C 的汉字补集，不含 A 的三套字体文件
- `assets/` — 样式与脚本（自制 SVG，无默认图表库皮肤）
- `review/` — 自查截图（Playwright / Chromium，file://）
- `src/` — 从原文生成衍生文件与截图的脚本
