# 室况 — 方向样品

这是一份**方向样品**，不是已经确定的毕业设计题目，也不代表唯一候选。它沿着「STM32 多传感器采集 + 数据链路 + 交互可视化」做成：把模拟节点的半小时读数，经示意串口入库，做成给教室、实验室或办公室管理者看的室内环境监测套件。要讲的是采集 → 存储 → 分析 → 产品，不是一堆没有场景的读数，也不是选题 C「节点与格点」那种装置感对照页。

主件是可交互页面，海报是同一主题的静态展板。作者向：Seven（何谭昕）。设计署名：Lumen。与选题 A（`../`，时刻的坡度）和选题 C（`../c-sensing/`，节点与格点）同属一套部门作品的兄弟样本，字体复用 A 已落地的 IBM Plex / Newsreader / Noto Serif SC，氛围改为产品看板 / 设备套件。数据以 Atlas 提供的模拟小样本为准。

本目录是选题 B 的单独成品。请不要改动 `../` 根目录里 A 的现有文件，也不要改动 `../c-sensing/` 里 C 的交互页、海报图或 HTML。

## 如何打开

单机即可，不依赖网络 CDN。脚本与数据在本目录；主体字体在上一级 `../fonts/`，本目录只补了一份 B 页面多出来的汉字子集 `fonts/NotoSerifSC-b.woff2`，没有复制 A 的字体文件。

**推荐：直接用浏览器打开主件**

- 双击 `index.html`，或用浏览器打开该文件（`file://` 即可）。
- 海报原件是 `poster.html`；交付用的锁字静态图是 `poster.png`（以及 `poster.pdf`）。

**可选：本地静态服务**（不是必须）

在本目录执行：

```bash
python3 -m http.server 8768
```

然后访问 `http://127.0.0.1:8768/index.html`。

交互：在值守带上拖曳或按左右方向键读取某一瞬间；顶部「教室 / 实验室 / 办公室」只切换产品文案框，数据始终是同一条模拟流，不是三间实测房间。右侧可见推断的套件构成与示意串口入库行。

## 哪些是算出来的，哪些是设计解读

**由样本算出（事实；数值本身仍来自模拟流）**

- 室内各通道的均值、极差、标准差、首末五分钟均值，以及 181 个采样点的时序。
- 设计口径下的落入计数：温度 20–26 °C 为 0 / 181（全部略高于上沿，最低 26.18 °C）；相对湿度 40–60% 为 181 / 181；照度 ≥ 300 lx 为 61 / 181（首五分钟 22 / 30，末五分钟 0 / 30）。计数是按该口径套到本条模拟流上得出的，口径本身不是标准。

**推断或设计解读（已在画面标明）**

- 主人已确认板型为 **正点原子 STM32F407ZGT6 开发板**（2026-11-11）。具体是哪一套件、已接哪些传感器仍未见清单；固件与页面数据均为模拟，未实机烧录。
- 传感器品类、总线与引脚（BME280 / BH1750 / MQ135 及 I2C1、ADC1）均为推断，不是已核实的物料表。
- MQ135 的气体指数由原始 ADC 按发明系数换算，不是标定 ppm，不做浓度告警。
- 片内温度 MCU_TS 更适于相对变化，**不能当作室内气温**。本列仍是模拟值。
- 舒适带 20–26 °C、40–60%、阅读照度 300 lx 是设计口径，不是国家标准，也不是本样品的实测结论。
- 教室 / 实验室 / 办公室是产品文案框，不是三间实测房间。
- 中文标题「室况」是样品名称，不是已定的毕业设计题目。

## 目录

- `index.html` — 可交互主成品（双击可打开）
- `poster.html` — 海报排版原件
- `poster.png` / `poster.pdf` — 锁字静态海报
- `data/` — 小样本原文、SOURCE.md、衍生 `specimen.js`
- `fonts/` — 仅 B 的汉字补集，不含 A 的三套字体文件

- `review/` — 自查截图（Playwright / Chromium，file://）
- `src/` — 从原文生成衍生文件与截图的脚本
