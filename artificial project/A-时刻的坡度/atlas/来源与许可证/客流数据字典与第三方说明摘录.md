# 客流数据字典与第三方说明摘录

采集时间：2026-11-11（Asia/Shanghai，UTC+8）

## 官方 Data Dictionary（Beginning 2025 附件）

来源 PDF（WebFetch）：https://data.ny.gov/api/views/5wq4-mkjj/files/3ad6ff48-c4f5-474c-8c5d-2a51173bd554?filename=MTA_SubwayHourlyRidership_DataDictionary.pdf

同日官方 API 元数据 `https://data.ny.gov/api/views/5wq4-mkjj.json` 的字段 `description` 与字典一致，转写更完整，下列说明以元数据描述为主，字典 PDF 作交叉核对。

| 字段 | 类型（元数据） | 官方说明（摘译/原文要点） |
| --- | --- | --- |
| transit_timestamp | calendar_date | Timestamp payment took place in local time. All transactions here are rounded down to the nearest hour. 例：1:37pm 记为 1pm。 |
| transit_mode | text | Distinguishes between the subway, Staten Island Railway, and the Roosevelt Island Tram |
| station_complex_id | text | A unique identifier for station complexes |
| station_complex | text | 刷卡/拍卡发生的车站复合体。大型复合体（如 Times Square、Fulton Center）可含多条线路。名称括号内为线路，例如 Zerega Av (6)。 |
| borough | text | Bronx, Brooklyn, Manhattan, Queens（元数据原文如此；实际数据中尚有 Staten Island，见样品） |
| payment_method | text | OMNY or MetroCard |
| fare_class_category | text | 票种归并类别。字典列举 MetroCard – Fair Fare / Full Fare / Other / Senior & Disability / Students / Unlimited 30-Day / Unlimited 7-Day，以及 OMNY – Full Fare / Other / Seniors & Disabilities |
| ridership | number | Total number of riders that entered a subway complex via OMNY or MetroCard at the specific hour and for that specific fare type. |
| transfers | number | 经免费巴士换乘或网络外换乘进入的人数。**已包含在 ridership 中**，不可再与 ridership 相加。复合体内部换乘不计入。 |
| latitude, longitude | number | 该 subway complex 的经纬度 |
| georeference | point | Open Data 平台根据坐标生成的 POINT 字段 |

注意（实测，非字典原文）：官方 SODA 与 transitlab parquet 中的票种字符串使用 `OMNY - Seniors & Disability`（Disability 为单数，连字符为 " - "），与字典中的 “OMNY – Seniors & Disabilities” 写法不完全相同。请以实际文件取值为准。Beginning 2025 元数据里 `transfers` 的 smallest 为 -30.0，存在负值可能，分析时不要假定非负。

## transitlab.nyc 说明页摘录

来源：https://docs.transitlab.nyc/datasets/subway-hourly-ridership/  
采集：本机 curl / WebFetch，2026-11-11。

该页写明（要点）：

- “The MTA's own estimate, copied from data.ny.gov.”
- 源数据集：subway hourly ridership 2017-2019、2020-2024、Beginning 2025。
- License 一栏写 “NY open data terms”。这是**第三方对其镜像的声明**，不是 data.ny.gov 条目里填好的标准许可证字段。
- 相对官方文件改了三件事：列类型（时间戳、计数为整数）；按月分文件；去掉重复经纬度的 `georeference` 列。“Values are the MTA’s.”
- 行是“某一车站复合体、某一小时、某一票种的进站人数”。进站（entries）不是完整出行（trips）。复合体内部换车不计。
- 时间是 New York local time，无时区后缀。
- “The MTA adds to it weekly and revises it. The last days of the newest month are not there yet...”
- 页上数字 “Rows 224,430,037 / Size 533 MB / ... from catalog.json, 2026-10-08” 是**第三方在 2026-10-08 的目录数字**，不是今晚从官方 API 读到的行数。
